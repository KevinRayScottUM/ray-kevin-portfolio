这篇笔记基于我实现的一种猜数游戏策略。游戏表面简单，结构却更接近部分可观测搜索，而不是普通二分查找。它是单人、随机、不完全信息游戏：玩家既不知道当前隐藏数 `N`，也不知道移动参数 `P`。

关键规则是不对称的。猜高时，`N` 不变，搜索范围可以安全缩小；猜低时，服务器会将 `P` 加到 `N` 上，让目标上移。因此，一次猜低不仅提供信息，还改变了游戏状态。

最初的基线是带 60% 启发式的贪心搜索。它不选当前区间中点，而选择约 60% 的位置。这样略高于中位数的猜测可降低猜低、推动 `N` 上移的概率。它比普通二分查找更符合规则，但仍只维护粗略的上下界，不知道哪些 `(N, P)` 组合仍可能成立。

当前实现的初始信念集合为：

<div class="math-block">S0 = {(N, P) : 1 <= N <= 1000, 1 <= P <= 200}</div>

改进策略称为 Possible State Greedy Search。它一开始存储所有候选状态，每次收到服务器反馈后删除不可能的状态。猜测为 `g` 时，若猜大了，删除所有 `N >= g` 的状态；若猜小了，删除所有 `N <= g` 的状态，并推进剩余状态：

<div class="math-block">S_{t+1} = {(N + P, P) : (N, P) in S_t and N > g}</div>

更新后，算法提取剩余可能的 `N`，排序并选择 60% 分位作为下一次猜测。它保留基线直觉，但显式感知状态：猜测不再来自粗略区间，而是来自实际存活的状态集合。

当可能范围变小时，策略切换为从高到低扫描。因为在窄区间中，猜高比猜低更安全：它缩小候选范围，却不移动 `N`。算法因此在接近结束时更加保守，避免反复猜低导致隐藏值持续漂移。

在一次 10 局评估中，最多尝试 63 次，最少 5 次，平均 29 次。不同隐藏 `(N, P)` 组合仍会带来明显波动，但显式建模状态演化，让方法比简单基线更可控。

一个自然的后续改进，是同时按后验不确定性与转移代价评价候选猜测：

<div class="math-block">score(g) = E[|S_{t+1}(g, r)|] + lambda * P(response = "+") * E[P | N > g]</div>

这会将启发式提升为转移感知策略。目标不只是减少可能状态，还要避免容易引起目标上移的猜测。它体现了一个更一般的 AI 思想：当动作会改变隐藏状态时，搜索应同时优化信息增益与状态转移风险。

我的主要体会是，这个问题鼓励我们超越固定公式。60% 贪心规则是有用的先验，更重要的思想却是维护并忠实更新信念状态。环境会因错误而移动时，搜索策略必须成为游戏的模型，而不仅是一串猜测。
